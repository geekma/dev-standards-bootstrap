## 接口总表（方法/路径/版本/状态）
[必填] 表：方法 / 路径 / 版本 / 状态（现行/deprecated/已移除）/ 关联 REQ-DES / 所属功能目录。字段级契约唯一权威在各功能 01/03，本册管全景与状态。

## 事件与消息契约
[必填] 表：事件/消息名 / 生产方 / 消费方 / 载荷要点 / 版本；无则写"当前无事件契约"（禁止留空）。

## 破坏性变更与弃用时间线
[必填] 追加式：破坏性变更 / 过渡期 / 移除日期（对齐 §2.13.3），旧行不改写。

## 消费方清单
[必填] 表：接口/事件 / 内外部消费方 / 兼容责任；变更影响面判定（02-impact）必查本表。
